# weragen-site

Лендинг weragen, открытой платформы для ИИ-автоматизаций. Статический сайт на Astro,
публикуется на GitHub Pages: <https://egsp.github.io/weragen-site/>.

Лендинг состоит из одной страницы. Сверху вниз на ней идут главный заголовок с полосой
фактов, возможности платформы, блок о нагрузке и квотах, схема контура организации, блок
об управлении и контроле, карточки о том, чем weragen не является, блок об открытом коде
и раздел о помощи.

Оформление чёрно-белое, со светлой и тёмной темой. Тема берётся из настроек системы,
переключатель внизу страницы меняет её, выбор хранится в браузере. Цвет есть только
у раздела о помощи. Шрифты IBM Plex Sans и IBM Plex Mono.

О помощи и внедрении говорится только в последнем разделе. В нём две части: сообщество
и внедрение под ключ.

Прежние варианты страницы остались в истории. Первый набор лежит в ветке
`feat/landing/claude-first-draft`, второй в коммите `e194314` ветки `feat/landing/claude`.

## Правила текста

Тексты лендинга опираются на обсуждение концепции, а не на нынешний код платформы: её API
ещё обсуждается. Требования автора проекта:

- сначала польза, проблемы в заголовки не выносятся;
- коротко, одно-два предложения на блок;
- "сервис", а не "программа";
- без длинного тире, кавычек-ёлочек, пояснений в скобках, двоеточий перед списками и точек
  в конце пунктов;
- без нумерации разделов, мелких подписей, кода и схем интерфейса.

## Устройство

| Путь | Назначение |
|---|---|
| `src/pages/index.astro` | страница лендинга |
| `src/data/content.ts` | все тексты страницы |
| `src/components/` | схема контура организации и переключатель темы |
| `src/layouts/Base.astro` | `<head>`, шрифты, выбор темы до первой отрисовки |
| `src/styles/base.css` | цвета обеих тем, шрифты и общие элементы |
| `src/lib/typograph.ts` | русская типографика: неразрывные пробелы после коротких слов |
| `astro.config.mjs` | адрес сайта и каталог публикации |
| `.github/workflows/pages.yml` | сборка и публикация |
| `AGENTS.md` | правила для агентов: ветки, worktree, сервер разработки |

## Команды

```bash
npm install
npm run dev        # сервер разработки: http://localhost:4321/weragen-site/
npm run check      # проверка типов
npm run build      # сборка в dist/
npm run preview    # просмотр собранного сайта
```

Требуется Node.js 22.12 или новее; CI использует версию из `.nvmrc`.

## Публикация

Workflow `.github/workflows/pages.yml` запускается в трёх случаях:

- push в `main`: проверка типов, сборка и публикация на GitHub Pages;
- pull request: проверка типов и сборка без публикации;
- ручной запуск на `main`: повторная публикация.

В настройках репозитория источник Pages: **GitHub Actions** (Settings → Pages → Source).

Для собственного домена в `astro.config.mjs` меняется `site` на адрес домена и удаляется
`base`, домен указывается в Settings → Pages → Custom domain, а у регистратора добавляется
DNS-запись по инструкции GitHub.
