# weragen-site

Лендинг weragen, открытой платформы для ИИ-автоматизаций. Статический сайт на Astro,
публикуется на GitHub Pages: <https://egsp.github.io/weragen-site/>.

В ветке `feat/landing/codex` подготовлены три чёрно-белых варианта лендинга:
«Сетка», «Типографика» и «Схема». Переключатели сверху меняют композицию и шрифт
(IBM Plex Sans или Golos Text) без перезагрузки. Они остаются доступны при прокрутке.
Шрифты поставляются вместе с сайтом, внешние сервисы шрифтов не используются.

В каждом варианте три раздела: вводный экран о продукте, возможности общей платформы
и подход к размещению и подключению программ. Тексты основаны на ответах в разделах 1–3
`docs/вопросы_2.md` из ветки `docs/product/questions` репозитория `EGSP/weragen`.
Сетка и иерархия вдохновлены IBM, лаконичная типографика и оформление взяты как направление
из OpenTUI. Схемы иллюстрируют концепцию, а не данные работающего сервера.
Продукт обозначен как находящийся в разработке; готовность будущих SDK и функций не обещается.

## Локальное сравнение

Работа Codex находится в `.worktrees/codex`. Из этого каталога:

```bash
npm install
npx astro dev --background --port 4332 --host 127.0.0.1
npx astro dev status
npx astro dev stop
```

Адрес: <http://localhost:4332/weragen-site/>. Выбор сохраняется в параметрах адреса:
`version=1`, `version=2` или `version=3`; `font=ibm` или `font=golos`.
Например: <http://localhost:4332/weragen-site/?version=2&font=golos>.
Кнопки «Назад» и «Вперёд» восстанавливают выбор. Без JavaScript доступен первый вариант
с рабочими ссылками на разделы. Переключение вариантов требует JavaScript.

По просьбе пользователя эта работа остаётся локальной: ветка не отправляется на GitHub,
публикация не запускается. Панель разработчика Astro скрыта, чтобы не мешать просмотру.

## Устройство

| Путь | Назначение |
|---|---|
| `src/pages/index.astro` | страница, переключатели версии и шрифта |
| `src/components/Landing.astro` | содержание трёх композиций |
| `src/components/Hub.astro` | схема связей платформы |
| `src/styles/landing.css` | оформление и адаптация к узким экранам |
| `public/favicon.svg` | значок сайта |
| `astro.config.mjs` | адрес сайта и каталог публикации |
| `.github/workflows/pages.yml` | сборка и публикация |
| `AGENTS.md` | правила для агентов: ветки, worktree, сервер разработки |

## Команды

```bash
npm install
npm run dev        # сервер разработки: http://localhost:4321/weragen-site/
npm run check      # проверка типов
npm run build      # сборка в dist/
npm run preview    # просмотр собранного сайта
```

Требуется Node.js 22.12 или новее; CI использует версию из `.nvmrc`.

## Публикация

Workflow `.github/workflows/pages.yml` запускается в трёх случаях:

- push в `main`: проверка типов, сборка и публикация на GitHub Pages;
- pull request: проверка типов и сборка без публикации;
- ручной запуск на `main`: повторная публикация.

В настройках репозитория источник Pages: **GitHub Actions** (Settings → Pages → Source).

Для собственного домена в `astro.config.mjs` меняется `site` на адрес домена и удаляется
`base`, домен указывается в Settings → Pages → Custom domain, а у регистратора добавляется
DNS-запись по инструкции GitHub.
