# weragen-site

Лендинг weragen, открытой платформы для ИИ-автоматизаций. Статический сайт на Astro,
публикуется на GitHub Pages: <https://egsp.github.io/weragen-site/>.

В ветке `feat/landing/sidebar-ibm` оставлен один лендинг на основе второго варианта.
В боковой панели находятся weragen и карточка open-source со знаком GitHub.
Панель остаётся на месте при прокрутке; на узких экранах она располагается над содержимым.
Хедер и переключатели удалены. Используется только IBM Plex Sans с обычным и жирным
начертаниями. Шрифт поставляется вместе с сайтом.

Основные разделы чередуют белый и чёрный фон. Возможности собраны в асимметричную
бенто-сетку, размещение показано в отдельном светлом контейнере. Подписи крупные,
декоративных значков и нумерации нет. Тексты сокращены до смысла возможности.
Названия моделей задаёт организация; фиксированные примеры имён убраны.

Внутренние ссылки подчёркнуты. Внешние ссылки оформлены карточками с иконкой перехода
и открываются в новой вкладке. У карточек возможностей нет поведения ссылки или кнопки.
Сайт работает без клиентского JavaScript. Старые параметры выбора варианта и шрифта
больше не меняют страницу.

Тексты основаны на разделах 1-3 `docs/вопросы_2.md` из ветки `docs/product/questions`
репозитория `EGSP/weragen` и на формулировках лендинга <http://localhost:4331/weragen-site/v1/>.
Широкая сетка первоначального третьего варианта, <https://www.ibm.com/us-en> и
<https://www.jetbrains.com/> служат ориентирами композиции. Схемы иллюстрируют концепцию
платформы. Продукт обозначен как находящийся в разработке.

## Локальный просмотр

Работа Codex находится в `.worktrees/codex`. Из этого каталога:

```bash
npm install
npx astro dev --background --port 4332 --host 127.0.0.1
npx astro dev status
npx astro dev stop
```

Адрес: <http://localhost:4332/weragen-site/>.

Первоначальное состояние сохранено коммитом `8f091fd`. Три полных варианта сохранены
коммитом `7adacfb` в ветке `feat/landing/codex-redesign`. Новая ветка создана от этого
состояния. Ветка не сливается с `main`, публикация не запускается.
Панель разработчика Astro скрыта, чтобы не мешать просмотру.

## Устройство

| Путь | Назначение |
|---|---|
| `src/pages/index.astro` | страница, метаданные и локальный шрифт |
| `src/components/Landing.astro` | боковая панель и содержимое лендинга |
| `src/components/ExternalArrow.astro` | иконка перехода на внешний ресурс |
| `src/components/GitHubIcon.astro` | знак GitHub внутри ссылки |
| `src/styles/landing.css` | сетка, секции и адаптация к узким экранам |
| `public/favicon.svg` | значок сайта |
| `astro.config.mjs` | адрес сайта и каталог публикации |
| `.github/workflows/pages.yml` | сборка и публикация |
| `AGENTS.md` | правила работы в репозитории |

## Команды

```bash
npm install
npm run dev        # сервер разработки: http://localhost:4321/weragen-site/
npm run check      # проверка типов
npm run build      # сборка в dist/
npm run preview    # просмотр собранного сайта
```

Требуется Node.js 22.12 или новее; CI использует версию из `.nvmrc`.

## Публикация

Workflow `.github/workflows/pages.yml` запускается в трёх случаях:

- push в `main`: проверка типов, сборка и публикация на GitHub Pages;
- pull request: проверка типов и сборка без публикации;
- ручной запуск на `main`: повторная публикация.

В настройках репозитория источник Pages: **GitHub Actions** (Settings → Pages → Source).

Для собственного домена в `astro.config.mjs` меняется `site` на адрес домена и удаляется
`base`, домен указывается в Settings → Pages → Custom domain, а у регистратора добавляется
DNS-запись по инструкции GitHub.
